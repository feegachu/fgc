# #405 화면 전환 검증 자료

2026-10-07, 로컬 PostgreSQL 시드와 실제 HTTP 응답으로 비교한 수동 캡처다.
운영 데이터·토큰·쿠키는 포함하지 않는다. 같은 기준월(2026-07)의 업무 대시보드를 비교했다.
영역별 측정값은 만들지 않았고, 전체 이미지의 픽셀 동일성도 검증 대상이 아니다. 공통 셸(#403) 차이는 비교 범위 밖이다.

| 화면 | 기존 Thymeleaf | React |
|---|---|---|
| DASH-W01 업무 대시보드 | [전](legacy-dashboard.png) | [후](react-dashboard.png) |

- 기존: `http://localhost:8081/`
- React: `http://localhost:5173/app/?month=2026-07`

같은 항목: KPI 카드 6종(제목·건수·보조 문구·색), 최근 예외 5행(심각도·유형·계약번호·내용·상태), 최근 통합검증 실행 3건(진행률 막대), 두 링크("예외함 전체 보기", "실행 목록").

캡처에서 보이는 차이:
- 최근 예외의 "예외 내용" 셀에 React는 "전체 보기" 토글이 항상 보인다. 기존 화면은 글이 잘릴 때만 표시한다.
- 계약번호 열 정렬이 React는 오른쪽, 기존은 왼쪽이다.
- 통합검증 실행 제목이 React는 `2026-08 · 2회차`, 기존은 `2026-08-01 · 2회차`다.
- 대시보드 탭의 닫기(×) 버튼은 기존 화면에만 보이고, 페이지 좌우 여백·사용자 표시 문구는 공통 셸(#403) 차이다.

검증: 프런트엔드 Vitest(대시보드 7개 포함), `tsc`, `eslint`가 통과했다.
