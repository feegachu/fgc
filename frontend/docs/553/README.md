# #553 수수료 지급 페이지네이션 간소화

상위 추적 이슈: #552. 공통 비활성·hover 스타일: #549 / PR #550.

## 변경

수수료 지급 건 목록에서 기존 공통 Pagination의 compact 모드를 사용합니다.

- 처음·마지막 텍스트 버튼 제거
- 이전·다음 화살표는 한 페이지 이동
- 현재 페이지 주변 숫자 최대 5개 표시
- 현재 / 전체 페이지 표시 및 검색조건·정산월 유지
- 첫·마지막 페이지에서 해당 방향 화살표 비활성

기존 Thymeleaf와 완전히 같은 동작을 요구하지 않는 의도적 UX 개선입니다. 다른 화면의 Pagination 모드와 공통 컴포넌트 코드는 변경하지 않습니다. 공통 비활성 표시와 현재 페이지 hover 색상은 PR #550의 변경을 사용하므로 해당 PR의 선행 병합을 권장합니다.

## 스크린샷

테스트 API 응답(총 12페이지, 현재 4페이지)으로 Chromium에서 촬영했습니다. 실제 고객 데이터는 사용하지 않았습니다.

## 검증

- 브라우저: 4 → 3 / 4 → 5, 숫자 6 선택, 1·12페이지 경계 확인
- 현재 페이지 주변 숫자 2·3·4·5·6 표시
- 이동 후 contractNo·settlementMonth·month·attributionImbalanceOnly 유지
- 375px 화면에서 페이지네이션 버튼이 뷰포트를 넘지 않음
- 기존 목록 테스트의 5페이지 그룹 이동 기대값을 인접 페이지 이동으로 변경
- 4페이지 양방향 이동·숫자 범위·마지막 경계·검색조건 유지 회귀 검사 추가
