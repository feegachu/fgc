# #553 수수료 지급 페이지네이션 간소화

상위 추적 이슈: #552. 공통 비활성·hover 스타일: #549 / PR #550.

## 변경

수수료 지급 건 목록에서 기존 공통 Pagination의 legacy 모드를 사용합니다.

- 처음·마지막 텍스트 버튼 제거
- 숫자를 1~5, 6~10처럼 최대 5개씩 묶어 표시
- 다음 화살표는 다음 묶음의 첫 페이지로 이동 (4 → 6)
- 이전 화살표는 이전 묶음의 마지막 페이지로 이동 (6 → 5)
- 숫자를 선택하면 해당 페이지로 직접 이동
- 첫 묶음에서는 이전, 마지막 묶음에서는 다음 화살표 비활성
- 활성 화살표에 title로 이전 5페이지·다음 5페이지 안내 제공
- 현재 / 전체 페이지 및 검색조건·정산월 유지

사용자 결정에 따라 한 페이지 이동 대신 기존 5페이지 묶음 이동으로 확정했습니다. 다른 화면의 이동 규칙은 유지합니다. 공통 Pagination의 legacy 화살표에도 같은 title 안내가 추가됩니다. 공통 비활성 표시와 현재 페이지 hover 색상은 병합된 PR #550의 CSS를 그대로 사용합니다. 최신 develop을 반영했으며 #554의 비교 diff에는 공통 CSS 중복 변경이 없습니다.
