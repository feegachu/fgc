## #725 확인된 누락과 수정

1. 페이지 이동 시 이전 결과를 유지하지만 갱신 안내가 없었다. `aria-busy`와 상태 문구를 표시하고 갱신 중 상세 이동·CSV를 잠근다. 이전 페이지를 새 페이지의 확정된 조회 결과로 오인하지 않게 한다.
2. 초기화가 정렬·선택 ID를 남겼다. 기본 조건·첫 페이지·기본 정렬로 되돌리고 선택 ID를 해제한다. 정산월은 유지한다. 일반 검색은 정렬을 유지하며 선택만 해제한다.
3. 같은 조건에서 조회를 누르면 URL이 같아 재조회되지 않았다. 첫 페이지·동일 조건은 명시적으로 refetch한다. 조회/초기화가 생성·저장 API를 호출하지 않는다.
4. 목록에 4년·7년 예정 결과의 지급 확정 제외 안내가 없었다. 선택 조건 또는 조회 결과가 해당 체계이면 안내한다.
5. 누락 회차·행 수·총액을 대시로만 표시했다. 자료 없음을 명시하고 실제 0원·음수와 구분한다. 계산 미준비 상태를 자료 없음으로 추정하거나 가짜 수치를 만들지 않는다.
