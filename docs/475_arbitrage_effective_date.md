# #475 차익거래 적용일 교정 및 검증 안내

## 변경과 근거

이슈에 정리된 REG-12·REG-19 및 SRC-025 Q11 기준으로, GA→FC 차익거래는 정책에 지정된 날짜 이상 체결된 신계약만 판정한다. 기존에는 계약일을 보지 않고 후보를 생성했다.

`ARBITRAGE` 정책 유형과 `ARBITRAGE_EFFECTIVE_CONTRACT_DATE` JSON 문자열(ISO 날짜)을 추가했다. 검증 기준일에 유효한 ACTIVE 정책이 정확히 하나여야 한다. 누락·중복·잘못된 값은 REVIEW_REQUIRED와 공통 예외로 남는다. 정책 또는 필수 적용일 값 누락은 POLICY_MISSING, 정책 중복은 POLICY_DUPLICATE, 잘못된 날짜는 DATA_QUALITY로 분류한다. 시행 전 계약은 CLEAR와 `candidateType=NOT_APPLICABLE`로 저장하며 금융 스냅샷이 없어도 후보·자료검토 예외를 생성하지 않는다. 계약일·정책 ID·적용일·사유를 계산 스냅샷에 보존한다.

수동·월·일일 검증이 공유하는 서비스 경로에서 처리한다. 환수 순액 계산, 해약환급금 36개월 경계, 후보의 현재/예상 초과 구분은 바꾸지 않는다. 비교용 JDBC 서비스도 같은 업무 변경을 반영한다.

## DB와 배포

- V45: 정책 유형 CHECK 확장만 수행. 기존 판정 및 정책을 덮어쓰지 않는다.
- V45.1: **데모 전용** 적용일 2026-03-01 정책을 작성자/승인자 분리 후 DRAFT→APPROVED→ACTIVE로 등록한다.
- 운영은 배포 전에 같은 키의 정식 정책을 담당자가 승인·등록해야 한다. 데모 승인을 운영 승인으로 간주하지 않는다. 미등록 시 검토필요로 처리된다.
- 이미 저장된 후보 및 예외는 자동 삭제하지 않는다. 기존 이력을 보존하고, 정상 재검증과 예외 처리 워크플로로 정리한다. 확정월 결과는 수정하지 않는다.
- 롤백은 이전 애플리케이션을 단순 재배포하면 새 정책 유형을 읽지 못할 수 있다. 신규 정책을 정식 RETIRED 처리하고 다운그레이드 호환성을 확인해야 한다. 기존 Flyway 파일 변경/삭제로 롤백하지 않는다.

병합·배포 순서는 #524(V45·V45.1) → #526(V46) → #527(V47) → #531(V49·V50)이다. 후속 PR의 채널 정리는 이 PR에서 중복 구현하지 않는다. V45.1 문구 교정은 아직 병합되지 않은 이 PR의 신규 마이그레이션에만 반영했으며, 이미 병합된 Flyway 파일은 수정하지 않는다.
