## 발견 사항과 수정 범위

1. 스케줄 응답의 null 가능한 원천 사건 ID와 확정 차단 사유가 OpenAPI에는 일반 정수/문자열로만 노출됐다. DTO 스키마 주석을 보강해 실제 서버 출력에서 null 가능성을 생성하고 TypeScript 계약까지 동기화한다.
2. 생성 사유의 OpenAPI 최소 길이가 0으로 표시됐다. 기존 NotBlank로 거절하던 빈 문자열의 길이 조건을 Size(min=1,max=40)에도 명시한다. 유효한 요청 범위는 바뀌지 않으며 스키마 최소 길이 1과 공백 금지를 설명한다. 정책 ID·원천 토큰의 조건부 필수 의미도 설명한다.
3. 가이드의 공통 타입·등록 대상·권한·마이그레이션 범위에서 추가 계약 불일치는 발견하지 않았다. 공개 API 경로·업무 계산·DB 상태 전이는 변경하지 않는다.
