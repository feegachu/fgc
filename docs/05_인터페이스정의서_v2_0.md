## 1. 공통 응답 규약

모든 JSON API는 다음 응답 봉투를 사용한다.

```json
{
  "data": {},
  "error": null,
  "requestId": "1ad49dcb-0e32-45ca-869b-9b9b035ea3b7"
}
```

| 필드 | 타입 | 필수 | 설명 |
|---|---|---:|---|
| `data` | Object, Array 또는 `null` | Y | 정상 응답 데이터. 오류 발생 시 `null` |
| `error` | Object 또는 `null` | Y | 오류 정보. 정상 응답 시 `null` |
| `error.code` | String | 오류 시 Y | FGC 표준 오류 코드 |
| `error.message` | String | 오류 시 Y | 사용자가 조치 방법을 알 수 있는 오류 설명 |
| `requestId` | UUID String | Y | 요청·응답 추적 식별자 |

## 2. 기준정보 API

### 2.1 IF-API-08 수수료 항목 기준정보 조회·선택

기준일자에 유효한 수수료 항목을 조회한다. 지급 건 목록의 검색조건과 지급 건 등록·수정 화면의 선택값으로 사용한다.

1,200% 한도 산입 여부는 수수료 항목의 고정 속성이 아니다. 룰셋 버전별 `cap_rule_item`에서 `INCLUDED`, `EXCLUDED`, `REVIEW_REQUIRED`로 결정하므로 이 API에서 산입 여부를 반환하거나 계산하지 않는다.

#### 기본 정보

| 항목 | 내용 |
|---|---|
| 기능 요구사항 | FUN-009 |
| Method | `GET` |
| URL | `/api/base/commission-items` |
| 호출 방식 | MPA 화면의 서버 모델 구성 또는 Ajax 조회 |
| 인증 | 필수 |
| 허용 역할 | 인증된 전체 역할 (`SYSTEM_ADMIN`, `GA_ADMIN`, `SETTLEMENT`, `COMPLIANCE`) |
| 주 테이블 | `fgc.commission_item` |
| 정렬 | `item_code` 오름차순 |

#### 요청 파라미터

| 이름 | 위치 | 타입 | 필수 | 형식 | 설명 |
|---|---|---|---:|---|---|
| `asOf` | Query | Date | Y | `yyyy-MM-dd` | 수수료 항목 유효 여부를 판단할 기준일자 |

요청 예시:

```http
GET /api/base/commission-items?asOf=2026-07-31
Authorization: <인증 세션 또는 인증 정보>
```

#### 조회 조건

다음 조건을 모두 만족하는 항목만 반환한다.

```sql
active_yn = TRUE
AND effective_from <= :asOf
AND (effective_to IS NULL OR effective_to >= :asOf)
```

유효기간의 시작일과 종료일은 모두 포함한다. 조회 결과가 없으면 오류가 아닌 빈 배열을 반환한다.

#### 정상 응답

HTTP Status: `200 OK`

| 필드 | 타입 | 필수 | 설명 | 예시 |
|---|---|---:|---|---|
| `data[].itemCode` | String | Y | 수수료 항목 코드 | `BASE_COMMISSION` |
| `data[].itemName` | String | Y | 화면 표시용 수수료 항목명 | `FC 기본수수료` |
| `data[].cashflowType` | String | Y | 현금흐름 구분 | `PAYMENT` |
| `data[].itemCategory` | String | Y | 수수료 항목 분류 | `SALES` |
| `error` | `null` | Y | 정상 응답이므로 `null` | `null` |
| `requestId` | UUID String | Y | 요청 추적 식별자 | UUID |

`cashflowType` 허용값:

| 값 | 화면 표시 | 의미 |
|---|---|---|
| `PAYMENT` | 지급 | 지급되는 금액 |
| `DEDUCTION` | 차감 | 환수·회수 등 차감되는 금액 |

정상 응답 예시:

```json
{
  "data": [
    {
      "itemCode": "BASE_COMMISSION",
      "itemName": "FC 기본수수료",
      "cashflowType": "PAYMENT",
      "itemCategory": "SALES"
    },
    {
      "itemCode": "CLAWBACK",
      "itemName": "환수",
      "cashflowType": "DEDUCTION",
      "itemCategory": "CLAWBACK"
    }
  ],
  "error": null,
  "requestId": "1ad49dcb-0e32-45ca-869b-9b9b035ea3b7"
}
```

빈 결과 응답 예시:

```json
{
  "data": [],
  "error": null,
  "requestId": "66a1cc39-097c-46c5-b51d-764eb3a8497a"
}
```

#### 오류 응답

| 상황 | HTTP Status | 오류 코드 | 메시지 |
|---|---:|---|---|
| `asOf` 누락 | 400 | `FGC-COM-001` | `기준일자(asOf)는 필수입니다. yyyy-MM-dd 형식으로 입력하세요.` |
| `asOf` 형식 오류 | 400 | `FGC-COM-001` | `기준일자(asOf)는 yyyy-MM-dd 형식이어야 합니다.` |
| 미인증 요청 | 401 | Spring Security 인증 오류 | 인증 후 다시 요청해야 한다. |

날짜 형식 오류 응답 예시:

```json
{
  "data": null,
  "error": {
    "code": "FGC-COM-001",
    "message": "기준일자(asOf)는 yyyy-MM-dd 형식이어야 합니다."
  },
  "requestId": "4737ce4a-b8ec-4db1-8561-24bbc9323d0e"
}
```

#### 화면 연계

화면의 수수료 항목 `<select>`는 다음과 같이 구성한다.

```html
<option value="BASE_COMMISSION">FC 기본수수료</option>
```

| API 필드 | 화면 사용처 |
|---|---|
| `itemCode` | `<option value>` 및 지급 건 저장·검색 요청값 |
| `itemName` | 선택박스와 목록의 표시 문자열 |
| `cashflowType` | 지급/차감 필드 기본값 및 일관성 검증 |
| `itemCategory` | 화면 분류·그룹 표시가 필요한 경우 사용 |

`TRAN-W01` 지급 건 목록의 나머지 열은 FUN-065의 지급 건 목록 API에서 조회한다. IF-API-08은 지급단계, 업무키, 정산월, 설계사, 금액, 상태, 귀속 건수를 반환하지 않는다.

#### 완료·검증 기준

- 기준일자에 유효하고 활성화된 항목만 반환한다.
- 유효기간 시작일과 종료일 당일의 항목을 포함한다.
- 결과가 없으면 `200 OK`와 빈 배열을 반환한다.
- 잘못된 날짜 또는 누락된 날짜는 `400 Bad Request`로 반환한다.
- 인증된 모든 역할이 같은 결과를 조회할 수 있다.
- 응답에 1,200% 산입 여부를 포함하지 않는다.
- Swagger UI와 `/v3/api-docs`에서 API 계약을 확인할 수 있다.
