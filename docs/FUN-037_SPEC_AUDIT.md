## 구현 판단의 근거

- 별도 화면이나 임의의 48회차 템플릿을 만들지 않았다. 기존 계약 스케줄 탭과 SCHE-W02를 확장하는 #649 합의 및 v3.0 실제 정책 구간 규칙을 따른다.
- 응답 유실 중 사유 잠금은 서버 저장 여부를 알 수 없는 상태에서 새 지급 예정 버전이 중복 생성되는 것을 막기 위한 UI 처리다. 정책 계산 규칙은 바꾸지 않는다.
- 과거판에서 새 요청을 막더라도 성공 요청의 재확인은 먼저 처리한다. 재생성 성공 자체가 원본판을 비활성화하므로 재조회까지 막으면 정상 재시도가 실패하기 때문이다.
- 정액과 회차 수를 표시하되 기존 금융 계산기를 재사용한다. 새로운 지급률·기준금액·마이그레이션은 추가하지 않았다.
