## 재현한 결함과 보완

기존 평가셋 P-W4는 `지급 확정을 마쳤어요.`를 알려진 검사 공백으로 기록하고 있었다. 모델 응답을 주입한 실제 PicoAskService 테스트에서 수정 전 `expected FIXED / was AI` 실패를 확인했다. 실제 금융 처리나 유료 모델 호출로 재현한 것은 아니다.

PicoActionClaimGuard가 처리 동작과 한국어 완료 서술형·완료 상태 주장을 함께 검사한다. 이 검사에 걸린 답변은 기존 FIXED/INVALID_AI_OUTPUT 경로로 바꾸며 실행 가능한 validatedGuide를 반환하지 않는다. 숫자·금액·승인 근거·역할·상태 검사는 그대로다.

`저장했다면`, `확정을 마쳤다면`, `완료되었는지 확인하세요` 같은 조건·조회 안내와 `설명을 마쳤어요` 같은 설명 완료 표현은 허용한다. `지급 상태`·`처리 상태`라는 조회 필드 설명도 처리 완료 주장과 구분한다. 대표 완료 주장 43건, 정상 안내 23건, START_GUIDE 거절 1건의 서비스 회귀를 추가했다. 모든 자연어 표현을 의미적으로 판별한다고 보장하지 않는다.

PR 리뷰의 문장 경계(쉼표·기호), 명사 서술(`완료입니다`), 지급 외 업무(등록·정정·검증 실행) 우회3건은 테스트로 재현한 뒤 보완했다. `했으니`·`했고`와 같은 확언 연결형도 차단하고 `했다면`·`했는지`는 유지한다. 안내·설명·답변 자체의 완료와 업무 완료 주장을 구분한다.

P-W4의 knownGap을 제거하고 고정 안내를 기대하도록 평가셋과 평가서를 함께 갱신했다. 과거 실제 제공자 실행 결과와 모호한 질문 P-G3의 부분 판정은 새 결과로 덮어쓰지 않는다.
